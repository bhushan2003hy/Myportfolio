## Brand & Style

This design system expresses the discipline, analytical depth, and production rigor of a Full-Stack Python Software Engineer and Mumbai University Computer Engineering graduate. It merges structural software architecture with a high-end, contemporary developer aesthetic.

The visual mood bridges deep system architecture with sleek digital interfaces. The emotional response is technical authority, understated confidence, algorithmic precision, and high craft.

### Visual Architecture
- **Technical Minimalism & Glass Layering:** High-depth dark-mode canvas accented with ultra-subtle translucent glass cards (`backdrop-blur-md`), precise 1px borders, and disciplined, vibrant computational glow accents.
- **Data & Metric Driven:** Prominence is given to quantifiable achievements (latency reductions, RPS throughput, test coverage, uptime) through clean numerical readouts, modular micro-panels, and monospaced syntax detailing.
- **Editorial Engineering:** Restrained layouts that reject generic portfolio fluff, prioritizing structural clarity, clean terminal-inspired headers, and interactive architecture showcases.

## Colors

The palette is engineered specifically for immersive, low-fatigue dark interfaces, utilizing deep slate-black foundations counterbalanced by high-precision chromatic indicators.

### Palette Architecture
- **Primary Canvas (`#0B0F19`):** Deep abyssal slate providing infinite depth and high contrast for text hierarchies.
- **Surface Elevation 1 (`#111827`):** Base structural container color for section cards and panel surfaces.
- **Surface Elevation 2 (`#1E293B`):** Elevated elements, active tabs, and nested syntax blocks.
- **Electric Indigo (`#6366F1`):** Primary interaction accent, key CTA anchor, and primary focus indicator.
- **Cyan Spark (`#06B6D4`):** Secondary accent for asynchronous operations, API telemetry, dynamic tags, and interactive links.
- **Emerald Pulse (`#10B981`):** Functional indicator for production readiness, passing builds, live deployment statuses, and performance gains.
- **Slate Textures (`#94A3B8` / `#F8FAFC`):** Primary text sits at crisp high-contrast off-white (`#F8FAFC`), secondary metadata at muted slate (`#94A3B8`), and structural divider borders strictly at translucent slate (`rgba(255, 255, 255, 0.08)`).

## Typography

Typography establishes an intentional cadence between human-readable editorial clarity and monospaced programmatic logic.

- **Headlines (Plus Jakarta Sans):** Geometric, precise curves create modern visual authority without feeling generic. Tight negative tracking gives high-impact headlines an architectural density.
- **Body & Editorial (Inter):** Applied across project narratives, systemic case studies, and engineering breakdowns for optimal neutral legibility.
- **Technical & Metrics (JetBrains Mono):** Reserved for technical tags, Python stack descriptors, performance metrics, API endpoints, and direct shell or code representations.

## Layout & Spacing

The layout is built upon a 12-column dynamic grid system capped at a maximum container width of `1280px` to maintain optimal scanning efficiency.

### Breakpoint Strategy
- **Mobile (< 768px):** 4-column layout. Structural margin sets to `1.25rem`, gutters drop to `1rem`. Monolithic stacks for cards, with horizontal scrolling enabled for inline tech badges and metric tiles.
- **Tablet (768px - 1024px):** 8-column layout. Margins expand to `2rem`. Project cards arrange in 2-column grids with sticky table-of-contents elements collapsible into mobile drawer states.
- **Desktop (> 1024px):** 12-column layout. Outer canvas margins expand to `3rem`. Complex multi-panel dashboard views, terminal windows side-by-side with architectural specs, and persistent asymmetric navigation columns.

### Rhythmic Scale
Spacing relies on binary base-8 spatial units: `space-xs` (4px) for micro-alignments inside badges; `space-sm` (8px) for badge internals and icon gaps; `space-md` (16px) for interior component padding; `space-lg` (24px) for card interiors; and `space-xl` (40px) for layout segment separation.

## Elevation & Depth

Depth is articulated through translucency, fine linear borders, and focused ambient glows rather than muddy drop shadows.

### Glassmorphism & Tonal Surfaces
- **Base Canvas:** Solid `#0B0F19` void background with an optional micro-dot grid pattern (`rgba(255, 255, 255, 0.03)` on 24px intervals).
- **Glassmorphic Surface:** Cards employ background fills of `rgba(17, 24, 39, 0.65)` layered over `backdrop-blur-md` (12px).
- **Hairline Outlines:** All elevated containers utilize 1px solid borders set to `rgba(255, 255, 255, 0.08)`. On hover, the border seamlessly transitions to `rgba(99, 102, 241, 0.4)` or `rgba(6, 182, 212, 0.4)`.

### Chromatic Glow & Cast
- **Interactive Luminescence:** Primary interactive triggers project a subtle radial glow behind their perimeter (`0 0 24px -4px rgba(99, 102, 241, 0.35)`).
- **Status Luminescence:** Live status pills project a concentrated green halo (`0 0 10px rgba(16, 185, 129, 0.5)`).

## Shapes

The design system maintains a structured, software-engineered profile using clean, controlled corners.

- **Containers & Glass Cards:** Use `rounded-lg` (0.5rem / 8px) to balance modern softness with architectural containment.
- **Code Blocks & Terminal Windows:** Use `rounded-md` (0.375rem / 6px) to maintain the crisp mechanical feel of CLI environments.
- **Badges, Tags, and Status Rings:** Use `rounded-full` or `rounded-sm` (0.25rem / 4px) depending on semantic usage: status pills are fully rounded pills, while technology badges (e.g., `FastAPI`, `PostgreSQL`, `Docker`) use structured 4px corners to communicate modular building blocks.

## Components

### Buttons
- **Primary Button:** High-contrast background filled with Electric Indigo (`#6366F1`), text in `#FFFFFF`, font `Inter` semibold (14px). Features a 1px border (`rgba(255, 255, 255, 0.2)` inset) and a faint interactive shadow. Hover activates slight luminance scaling and cyan border shift.
- **Secondary / Terminal Button:** Ghost container with `rgba(17, 24, 39, 0.8)` background, 1px border `rgba(255, 255, 255, 0.12)`, text `#94A3B8`. Hover transitions text to `#F8FAFC` and border to `#6366F1`.
- **Command Action Button:** Monospaced label (`JetBrains Mono`), left-aligned `$` prompt or icon, right-aligned keyboard shortcut tag (e.g., `⌘K`).

### Tech Stack Chips & Status Badges
- **Tech Stack Badges:** Compact 4px-radius boxes containing `label-badge` typography. Background: `rgba(30, 41, 59, 0.6)`, text: `#94A3B8`, border: `1px solid rgba(255, 255, 255, 0.06)`. On hover: border tints to accent Cyan (`#06B6D4`) with text shifting to `#F8FAFC`.
- **System Status Badge:** Fully rounded pill with an emerald pulsing point indicator: 6px radial dot (`#10B981`) enveloped by an animated ping ring, displaying live availability or deployment status.

### Glassmorphic Project & Case Study Cards
- Semi-translucent panels (`rgba(17, 24, 39, 0.7)`), 1px border in `rgba(255, 255, 255, 0.08)`, inner padding of `space-lg` (24px).
- Internal layout: Architecture diagram/preview at the top, followed by monospaced project categorical tags, bold title, compact engineering summary, live metric counters (e.g., `Latency: -42ms`, `Throughput: 12k RPS`), and GitHub/demo action links.

### Engineering Metric Displays
- Modular micro-cards highlighting measurable impact:
  - Metric figure using `metric-num` (`JetBrains Mono`, 32px, `#F8FAFC`).
  - Metric delta indicator with upward trend vector (`#10B981`).
  - Metric description set in `body-sm` (`#94A3B8`).

### Terminal / Code Snippet Windows
- Mac-inspired dark shell chrome with 3 top-left status controls (muted red, yellow, green 8px dots).
- Dark interior (`#080C14`), line numbers anchored in `#475569`, code tokens rendered in high-contrast Python syntax highlights (Indigo keywords, Cyan functions, Emerald strings, Orange decorators).
- Integrated top-right copy utility with instant confirmation state.

### Input Fields & Search (Command Palettes)
- Dark-mode input surfaces with background `#0E131F`, 1px border `rgba(255, 255, 255, 0.1)`.
- Typography in `Inter` 14px with `JetBrains Mono` placeholder text.
- Focus state activates an instantaneous 1px border glow in `#6366F1` with an outer ring blur (`0 0 0 2px rgba(99, 102, 241, 0.25)`).
